# Nero for Mac

Download the latest **Nero.dmg** from [Releases](https://github.com/Elimartain/nero-releases/releases/latest).

## First install

1. Open `Nero.dmg` and drag **Nero** into **Applications**.
2. Open Nero. If macOS says it can't check the app, open **System Settings > Privacy & Security**
   and choose **Open Anyway** (once).
3. Sign in with Microsoft.

## Updates

Nero checks for a new version every time it opens. When one is out it asks you to install it,
then downloads it, installs it and reopens by itself.
